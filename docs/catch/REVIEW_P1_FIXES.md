- **Sell is now real** (`modules/catch_sell.py`, `discord_bot/cogs/_views_catch_sell.py`, `tests/unit/test_catch_sell.py`). The Economy > Sell screen lists the player's creatures that are not favourites and not locked (10 per page, newest first), shows what each sells for, and needs a select plus an explicit **Sell for N coins** press (Cancel clears the choice). `sell_creature()` is the only code that pays coins for a creature: one transaction with `SELECT ... FOR UPDATE` on the creature row scoped by id, user_id and clone_key in SQL, refusal of favourites and locked creatures, `DELETE ...
