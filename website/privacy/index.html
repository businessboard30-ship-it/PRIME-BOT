Privacy Policy

PRIME BOT × WELCOME BOT · Last updated 12 October 2026

This page explains what data PRIME BOT × WELCOME BOT (“the bot”) collects and how it is used. The bot is operated by Maxwell Dumenya, a sole proprietor based in Ghana.

What we collect

  • Discord IDs (user, server, and channel IDs) needed to operate features you use — e.g. your economy balance, XP/level, warns, or premium status are all stored against your Discord user ID and the server’s ID.
  • Message content only where a feature requires it (e.g. auto-moderation’s word/invite/spam filters scan message text to enforce rules you or a server admin configured; AI chat/image features send your prompt to the underlying AI provider to generate a response).
  • Payment references (not full card details — payments are handled by a third-party payment processor, Gumroad or Paystack) when you use a paid feature.
  • Messages that Scam Shield removes as known scams: a copy (text and attachments, with the server and user IDs) is saved to a private Discord channel run by the operator, so the scam rules can be improved. Our database keeps only who, where, when and which rule matched, never the message text; those records are deleted after 180 days.
  • Optional linked accounts (media server, cloud folder) only if you choose to connect one, stored so the relevant feature keeps working until you disconnect it.
  • Server membership events: when someone joins or leaves a server where the bot is added, the bot sees their Discord ID, username, account creation date and join or leave time, and which invite they used if the invite tracker is turned on. This is used for welcome messages, verification, the join gate, invite tracking and moderation, and is stored with the server’s ID.

Why the bot reads members and messages

The bot uses two Discord permissions that need Discord’s approval. Server Members lets it react when someone joins or leaves and look up members for the features above. Message Content lets it read messages as they are sent to award XP, run auto-moderation filters, and answer commands and triggers a server admin configured. Message text is processed as it arrives and is not stored in our database. The spam filter keeps only a short one-way fingerprint of each message (not the words) for a few minutes to spot repeats. The only copy of message text we keep is the Scam Shield evidence copy described above, in a private Discord channel. The bot does not use message content to train AI or machine learning models.

Bots run from this service

This policy also covers every bot run from the same service, including white-label bots such as Welcome Bot. For those bots the operator is still Maxwell Dumenya. Bots run for a server owner keep only the details needed to run them, encrypted, until the owner removes them.

What we don’t do

We don’t sell your data. We don’t read or store messages outside of what a feature you’re actively using needs in order to work.

Web dashboard

If you sign in to the web dashboard with Discord, we store:

  • A record that you signed in, with your Discord display name and avatar. They are used to show you on the global leaderboard unless you switch that off on the Leaderboard page; everyone else sees you as Hidden player. No user ID is shown to other people. We also keep the days you used the dashboard (90 days, visible only to the bot owner).
  • Your level-up card design and any uploads, your AI provider keys if you add them (encrypted, never shown again), receipts for exports you save (the files are encrypted), your scheduled jobs, and renewal reminders.
  • If you connect GitHub (read-only), an encrypted access key. Disconnecting deletes it and tells GitHub to revoke it.
  • If you use member messaging, your friends list and messages (text only; deleted automatically after 30 days, or when you delete your data).

AI chats on the website are not stored; only a weekly count is kept. You can delete the dashboard data above yourself under Privacy & data in the dashboard. Payment records, your plans, weekly chat counters and in-server records (XP, coins, moderation) are kept.

Third parties

Depending on which features you use, data may be sent to: the AI provider powering chat/image features, the payment processor handling paid features (Gumroad or Paystack), and (only if you connect one yourself) a media server, cloud storage provider, or another Discord bot’s application.

Data retention & deletion

Feature-related data (balances, XP, warns, linked accounts, join records) is kept while you continue using the bot in a server. You can disconnect a linked account at any time with its corresponding command, and you can mute level-up pings from the leveling leaderboard. Server admins can turn off leveling, auto-moderation and invite tracking in their own server. Run /mydata in any server or in a DM with the bot to see what we hold and delete it yourself (you type DELETE MY DATA to confirm). Payments and plans, weekly usage counters and moderation records (warns, bans) are kept. Short-lived records are removed automatically: AI command logs after 90 days, and network and browser hashes from server listing visits after 30 days. To request full deletion of your data, or to opt out of having your activity tracked, email maxwelldumenya5@outlook.com with your Discord user ID; we will delete it or tell you why we cannot (for example payment records we must keep).

Children’s privacy

The bot is not directed at children under 13, consistent with Discord’s own minimum age requirement.

This website

This website is a static site. It does not use cookies, analytics or third-party scripts, and it does not collect personal data. Links to Discord and payment providers lead to services governed by their own policies.

Changes

This policy may be updated from time to time; continued use after a change means you accept the updated policy.

Contact

Questions about this policy, or to request data deletion: maxwelldumenya5@outlook.com, or use the bot’s /feedback command.
