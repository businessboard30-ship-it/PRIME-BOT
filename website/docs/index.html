Getting started

  1. Click Add WELCOME BOT or Add PRIME BOT on the home page and pick your server.
  2. Approve the permissions (listed below).
  3. Check your DMs: the server owner gets a setup message with a Turn on button for each feature. Each button applies sensible defaults.
  4. Fine-tune from /serversetup. Browse everything with /help.
  5. Move the bot’s role above any role it needs to hand out or manage, so Discord’s role hierarchy lets it work.

Permissions the bot asks for, and why

The invite link requests the full set below so that every feature works out of the box. You can narrow it in Discord’s permission picker, but features that need a removed permission will report “Missing Permissions”.

Kick Members, Ban MembersModeration commands, auto-moderation and anti-raid actions.
Moderate MembersTimeouts.
Manage RolesVerification roles, auto-roles, level-role rewards, reaction roles and custom roles. The bot’s role must sit above any role it assigns.
Manage ChannelsSetup helpers that create channels, verification channel locking, tickets and channel-name styling.
Manage MessagesAuto-moderation filters that remove messages.
View Channels, Send Messages, Embed Links, Attach Files, Read Message HistoryPosting panels, embeds and generated cards, and reading channel history where a feature needs it.
Add Reactions, Use External EmojisReaction-based features and panels.
Mention EveryoneUsed by the announcement command.
Manage WebhooksFeatures that post through webhooks.

FAQ

How do I add the bot?
Use the Add WELCOME BOT or Add PRIME BOT button on the home page, choose your server and approve the permissions. You need the Manage Server permission in that server.
The bot did not DM me. How do I start setup?
Run /start in your server to resend the setup DM, or open /serversetup to configure everything from one panel. If your DMs are closed, open them for the server and run /start again.
How do I set up verification?
Run /setupverification. It creates Unverified and Verified roles below the bot, locks channels for unverified members and posts the verify panel. New members press Verify and complete a Cloudflare Turnstile human check. Keep the bot’s role above those roles.
How do I set up anti-raid?
Run /antiraid to configure spike detection, lockdown and staff alerts. With Premium, Anti-raid Pro adds the join-profile filter, raid reports and quarantine-and-review.
How do I run applications for a role or staff?
Run /application to build a form with the wizard. The bot posts a panel with an Apply button, applicants answer in a pop-up, and staff accept or decline in a review channel. Free servers get 1 live form with 3 questions; Premium gives 10 forms, 5 questions, all colors and auto-role on accept.
How do I set up welcome cards?
Run /welcome (or turn on welcome messages from the setup DM) to choose the channel, theme, colors and message. Premium themes and custom backgrounds need the Welcome Card Pack, Ultra Welcome Pack or Go Premium.
How do I cancel Premium?
Cancelling stops future renewals; Premium stays active until the end of the period you already paid for. For Gumroad, use the manage-membership link in your Gumroad receipt email, or email us and we will help. Paystack payments (Ghana) cover 30 days and never renew, so there is nothing to cancel. Yearly and lifetime are one-time payments.
How do I request a refund?
Email maxwelldumenya5@outlook.com with your Discord user ID, the server ID (for server-wide purchases) and your payment reference. We aim to reply within a few business days. See the Refund Policy.
How do I delete my data?
Email maxwelldumenya5@outlook.com to request full deletion. You can also disconnect any linked account at any time with its own command. See the Privacy Policy.
The bot is not responding.
Check the status page for what to look at first, then ask in the support server.
Is it really free?
Yes. Adding and using the bot is free. Paid features are optional: Go Premium (per server) and a handful of one-time unlocks. All prices are in USD.
What does Go Premium cost?
$4/month, $36/year (25% off: 12 months for the price of 9) or $99.99 lifetime, one-time. It applies to the whole server, not to one member.
