About

Who runs this

PRIME BOT × WELCOME BOT is built and operated by Maxwell Dumenya, an independent developer.

Mission

Make it easy for any Discord server owner to set up a welcoming, safe and active community, without paying to get started. The bot is free to add and use; paid features are optional and clearly priced.

The operator

Maxwell Dumenya, independent developer. The bot, this website and customer support are run by one person.

How it started

PRIME BOT began with a small idea: I wanted to make a bot for my little sister's Discord server. I never expected it to grow this far. What started as a simple project became a bot used by communities far beyond that first server.

I don't have a lifelong passion for bots. I enjoy the fun part of creating, experimenting, solving problems and making things easier for people. Seeing something I build become genuinely useful is what keeps me going.

I use AI to help with debugging, exploring solutions, planning and some code writing. I research ideas, set the direction, review suggestions, test changes and take responsibility for the result. AI is a tool in my workflow, not a replacement for that work.

How I build

I respect developers who build everything from scratch. My workflow is different: I research community needs, plan what is worth building and use available tools to move faster. My personal estimate is around 70% my direction, decisions and hands-on effort, with 30% AI assistance. That is an estimate, not a measured statistic.

The important part is the work behind the result: choosing useful features, checking suggestions, testing changes, fixing problems and improving the experience. Different workflows can still produce thoughtful work.
